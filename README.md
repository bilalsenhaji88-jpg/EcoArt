# EcoArt

EcoArt is a static website for an artisan upcycling project.

## Project structure

- `index.html`, `produits.html`, `services.html`, `artisans.html`, and `impact.html` are the site pages.
- `css/` contains the page stylesheets and shared design variables.
- `assets/images/` contains the website images and logos.
- `assets/icons/` contains icons.
- `assets/source/` contains the original services-page archive.
- `charte-graphic/` contains the project graphic charter.

Open `index.html` in a browser to view the site.
